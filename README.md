# EphemeralLab

**Your development environment, ready in seconds.**

EphemeralLab is a self-service development environment provisioning platform that automates the creation, management and cleanup of isolated development environments.

## Core Features

* One-click development environment provisioning.
* Docker-based environment isolation.
* Automated environment expiration and cleanup.
* Resource allocation and monitoring.
* Reusable environment templates.
* GitHub repository integration.
* Cloud infrastructure automation.
* Environment usage and cost tracking.

## Technology Stack

* Frontend: React, TypeScript
* Backend: Python, FastAPI
* Database: PostgreSQL
* Containerisation: Docker
* Background Processing: Celery, Redis
* Cloud: AWS
* Infrastructure as Code: Terraform
* CI/CD: GitHub Actions
* Monitoring: Prometheus, Grafana

## Project Status

Under active development.

## Vision

To simplify development environment provisioning through automation, containerisation and cloud infrastructure management.
